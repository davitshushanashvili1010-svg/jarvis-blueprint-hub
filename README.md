# Jarvis Blueprint Hub

A dark cybernetic app prototype inspired by Jarvis-style control dashboards.

## Features
- Browse curated blueprint cards inspired by Google-style design systems
- Search and filter blueprint catalog
- Create a custom project from a command center panel
- Dark neon interface with dashboard-style layout
- Ready for expansion with auth, database, and real workflow integration

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Tech stack
- Next.js 14
- TypeScript
- Tailwind CSS
- React

## Notes
This is a UI-first prototype. The Google Blueprint integration and real project persistence can be added next through API connectors and a database layer.
